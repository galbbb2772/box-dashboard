# Box Dashboard

Public, read-only dashboard for the Box strategy family.

This repository intentionally contains only **public-safe aggregate outputs** such as strategy status, holdout summaries, and Forward OOS progress. Core strategy logic, parameters, research code, raw candidates, and trade-level evidence remain in the private `box-strategy-lab` repository.

## Pages

- Overview
- Strategy Registry
- Holdout Evidence
- Forward OOS
- Research Pipeline

## Deployment

GitHub Pages deploys automatically from `main`.
